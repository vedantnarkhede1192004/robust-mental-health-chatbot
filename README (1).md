# Mental Health Support Chatbot (Flask + local open-source LLM)

Backend-only chatbot API. Replies are generated by a language model (not rule-based),
running locally through Ollama, so it is **free** with no API key.

## Files
| File | Purpose |
|------|---------|
| `app_free.py` | Flask API (`/chat`, `/reset`, `/health`), safety classifier, reply generation |
| `db.py` | SQLite chat-history storage |
| `test_chat.py` | Manual test script |
| `requirements.txt` | Python dependencies |

## Setup
1. Install [Ollama](https://ollama.com/download)
2. `ollama pull llama3.2:3b`
3. `pip install -r requirements.txt`
4. `python app_free.py`
5. In another terminal: `python test_chat.py`

Use a different model: `CHAT_MODEL=qwen2.5:3b python app_free.py`

## API
- `POST /chat` body `{"session_id": "u1", "message": "..."}` returns `{"session_id", "reply", "risk"}`
- `POST /reset` body `{"session_id": "u1"}` clears that session's history
- `GET /health`

## How it works
1. The user message is saved to SQLite.
2. A model-based classifier labels risk as `none`, `elevated` or `crisis`
   (plus a small keyword backstop that can only raise the level).
3. The reply is generated with a system prompt tuned to the risk level.
4. On `crisis`, helpline numbers (India: 112, Tele-MANAS 14416) are appended.

## Important
- This is a support tool, **not** a replacement for professional help or a diagnosis tool.
- `chat.db` contains private conversations. Do not commit or share it.
- Test with many realistic messages and have a qualified person review the prompts before real users use it.
